A program that writes one sentence about the best meal ever had to
`/output/entry.txt`: a grandmother's rendang, simmered since dawn, eaten
standing in her kitchen doorway. Concrete, personal, one clean sentence —
built for the judge's brief (most concrete, most personal, most worth
remembering).

## Run

```sh
python3 main.py
```

Writes `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
Standard library only, no network.
